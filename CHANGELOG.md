# Changelog

## 0.2.1 — 2026-10-26

- AI Mode renders safe Markdown answers and offers Concise, Standard and Detailed response lengths with provider-side output caps.
- OpenAI, Google Gemini and Anthropic AI providers with saved per-provider keys, automatic model discovery and balanced model recommendations.
- Shared Code Board detail dialogs for files, areas, changes, features and commits, including author/date, Git history, staged and working-tree statuses, changed-file summaries and patch details.
- AI Explain from every Code Board card and details dialog.
- Expanded Studio Outline Icons for common language, web, database, configuration, build and lockfile types.
- More complete AI setup and Code Board documentation; release checksums generated consistently across PowerShell environments.

## 0.2.0 — 2026-10-26

- Studio N agency identity: Geist, charcoal surfaces, pills, pastel accents and the N/red-dot icon.
- Windows per-user installer and standalone portable packaging with checksums.
- Command progress, missing-provider explanations, cancellation and honest outcome feedback.
- Visible Git commit completion.
- Open VSX extension search/install and compatible VSIX support.
- Git-backed Code Board with Explain actions, plus AI Ask/Explain/Plan and reviewed single-file edits.
- Installation, update, extension and design-system documentation.

## 0.1.0 — 2026-10-26

Initial development release of studio-n-code.

- Independent desktop identity and original SVG/PNG/ICO application icon.
- Project, branch and run controls in a dedicated application header.
- Tool-window rails, dark theme, Inter typography and outline file icons.
- Search across files and workspace symbols, with 59 mapped actions.
- Commit checklist with explicit selected-file commits and amend support.
- Git branches, history graph, commit details and native file diffs.
- Real integrated terminal, Node debugging and language-provider integration.
- Pinned upstream source, Windows build scripts and persistent launch logs.
- Unit tests, headless webview interaction checks and desktop smoke tests.

This release is source-first and Windows x64 focused. Installer packaging, signed binaries, other platform builds and additional language tooling are future work.
