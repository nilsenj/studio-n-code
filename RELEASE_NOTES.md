# studio-n-code 0.2.0 preview

Standalone Windows x64 coding studio with Studio N styling, integrated Git tools, keyboard commands, visible command feedback and Open VSX extension installation.

Code Board organizes project files, areas, changes, features and Git history. Each card can be explained in AI Mode. AI Mode also supports project questions, plans and diff-reviewed single-file edits through a user-configured OpenAI-compatible endpoint. A model/account is not bundled.

Download `studio-n-code-0.2.0-windows-x64-setup.exe` for a per-user installation, or extract the portable ZIP and run `studio-n-code.exe`. No build tools are required. `SHA256SUMS.txt` contains file digests.

See [installation instructions](https://github.com/nilsenj/studio-n-code/blob/main/INSTALL.md) and [extension compatibility](https://github.com/nilsenj/studio-n-code/blob/main/docs/extensions.md).

This preview is unsigned and uses ordinary MSVC runtime libraries. Automatic updates and other platform packages are not available yet. Extensions requiring Microsoft-only services/licenses are not guaranteed to work. Save work before updating.
